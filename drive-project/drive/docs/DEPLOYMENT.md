# GoDrive Deployment Guide

## 🚀 Deploying to Production

This guide covers deploying the GoDrive application to Vercel (frontend) and Render (backend).

---

## 📱 Frontend Deployment (Vercel)

### Prerequisites
- GitHub account
- Vercel account (free tier works)

### Steps

1. **Push your code to GitHub**
   ```bash
   cd drive-ui
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin <your-repo-url>
   git push -u origin main
   ```

2. **Deploy to Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Click "Import Project"
   - Select your `drive-ui` repository
   - Vercel will auto-detect Next.js settings

3. **Configure Environment Variables**
   In Vercel dashboard, add:
   - `NEXT_PUBLIC_API_BASE_URL` = `https://your-backend-url.onrender.com`

4. **Update vercel.json**
   - Replace `your-backend-url.onrender.com` with your actual Render backend URL
   - Redeploy

## 🔧 Backend Deployment (Render)

### Option 1: Using Render Blueprint (Recommended)

1. **Push to GitHub**
   ```bash
   cd drive
   git init
   git add .
   git commit -m "Initial backend commit"
   git remote add origin <your-backend-repo-url>
   git push -u origin main
   ```

2. **Deploy via Render Dashboard**
   - Go to [render.com](https://render.com)
   - Click "New" → "Blueprint"
   - Connect your GitHub repository
   - Render will read `render.yaml` and create all services

3. **Run Migrations**
   After deployment, connect to your PostgreSQL instance and run:
   ```bash
   # Get shell access to your API service
   # Then run migrations
   migrate -path ./migrations -database "postgres://..." up
   ```

### Option 2: Manual Service Creation

If you prefer manual setup:

1. **Create PostgreSQL Database**
   - New → PostgreSQL
   - Name: `godrive-postgres`
   - Plan: Free

2. **Create MinIO Service** (Optional - or use AWS S3)
   - New → Private Service
   - Use `Dockerfile.minio`
   - Add persistent disk at `/data`

3. **Create API Service**
   - New → Web Service
   - Use main `Dockerfile`
   - Set environment variables (see render.yaml for reference)
   - Add health check: `/health/live`

## 🔐 Environment Variables Reference

### Backend (Render)
```bash
# Server
GODRIVE_API_HOST=0.0.0.0
GODRIVE_API_PORT=8080

# Database
POSTGRES_HOST=<from-render-postgres>
POSTGRES_PORT=5432
POSTGRES_USER=godrive_app
POSTGRES_PASSWORD=<auto-generated>
POSTGRES_DB=godrive
POSTGRES_SSL_MODE=require

# Object Storage (MinIO or S3)
MINIO_ENDPOINT=<minio-service-url>
MINIO_ROOT_USER=godrive
MINIO_ROOT_PASSWORD=<auto-generated>
MINIO_BUCKET=godrive
MINIO_USE_SSL=true

# Auth
GODRIVE_JWT_SECRET=<auto-generated-32-chars>
GODRIVE_JWT_REFRESH_SECRET=<auto-generated-64-chars>

# Logging
GODRIVE_LOG_LEVEL=info
ENVIRONMENT=production
```

### Frontend (Vercel)
```bash
NEXT_PUBLIC_API_BASE_URL=https://your-api.onrender.com
```

## 🧪 Post-Deployment Testing

1. **Test API Health**
   ```bash
   curl https://your-api.onrender.com/health/ready
   ```

2. **Test Registration**
   ```bash
   curl -X POST https://your-api.onrender.com/v1/auth/register \
     -H "Content-Type: application/json" \
     -d '{"email":"test@example.com","password":"password123"}'
   ```

3. **Access Swagger Docs**
   - Visit: `https://your-api.onrender.com/swagger/index.html`

4. **Test Frontend**
   - Visit your Vercel URL
   - Try logging in with the test account

## 🔄 CI/CD

Both Vercel and Render support automatic deployments:
- **Vercel**: Auto-deploys on push to `main` branch
- **Render**: Auto-deploys on push (enable in service settings)

## 🆘 Troubleshooting

### API won't start
- Check logs in Render dashboard
- Verify all environment variables are set
- Ensure database migrations ran successfully

### CORS errors
- Update `NEXT_PUBLIC_API_BASE_URL` in Vercel
- Check CORS middleware in backend

### Database connection failed
- Verify `POSTGRES_SSL_MODE=require` for Render
- Check database is in same region as API

## 📝 Notes

- **MinIO Alternative**: For production, consider using AWS S3, Cloudflare R2, or Backblaze B2 instead of self-hosted MinIO
- **Database Backups**: Enable automatic backups in Render PostgreSQL settings
- **SSL**: Both Vercel and Render provide free SSL certificates
- **Custom Domain**: Add your domain in Vercel/Render dashboard settings
